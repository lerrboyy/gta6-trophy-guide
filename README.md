Leonida Trophy Guide is an offline guide and tracker for all 55 GTA 6 trophies on PlayStation 5: every trophy with its official name, description and grade, a guide in our own words with its sources, a roadmap to the platinum, the 8 missable trophies flagged, and a checklist saved in the browser with export and import, filters by kind and grade, and a spoiler setting that hides story trophies until earned.

## Run it

```sh
node serve.ts
```
